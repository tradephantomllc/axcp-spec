# AXCP Trademark Policy

## 1. Purpose

This policy explains permitted use of the AXCP name.

## 2. Ownership

The "AXCP" name is owned by TradePhantom LLC. The Apache 2.0 license of AXCP Core does not grant trademark rights (see Section 6 of the license). No rights to the name are granted except as explicitly stated in this policy.

## 3. Permitted Nominative Use

The following uses are permitted without prior authorization:

- Referring to AXCP in text to describe compatibility, integration, or use (e.g., "works with AXCP", "compatible with AXCP")
- Use in articles, talks, tutorials, and documentation, provided it does not imply official endorsement or affiliation
- Accurate statements about the AXCP project in press coverage or technical analysis

## 4. Prohibited Use

The following uses are **not permitted** without written authorization:

- Using the AXCP name in a way that suggests official endorsement, partnership, or affiliation
- Using the AXCP name as, or as part of, your product or company name or branding
- Naming a product or service so that users could reasonably believe it is the official AXCP project or an official offering from TradePhantom LLC
- Any use that implies the AXCP project or TradePhantom LLC has reviewed, approved, or certified your product

## 5. Domain Names and Social Handles

Do not register domain names or social media handles that:
- Are confusingly similar to "AXCP"
- Imply official status or affiliation with the AXCP project
- Could mislead users into believing they represent the official project

## 6. Project Naming Guidance

When naming projects that work with AXCP:

**Acceptable:**
- "MyTool for AXCP"
- "Compatible with AXCP"
- "AXCP Integration for MyPlatform"
- "MyCompany's AXCP Connector"

**Not Acceptable (without authorization):**
- "AXCP Cloud"
- "AXCP Pro"
- "Official AXCP Service"
- "AXCP by MyCompany"

## 7. Permission Requests

For permission to use the AXCP name in ways not covered by this policy, email enterprise@getaxcp.com with the subject "Trademark Permission Request" and describe:

- Your organization
- The intended use of the AXCP name
- The context and duration of use

Please do not post permission requests in public GitHub issues.
