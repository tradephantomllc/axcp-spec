# AXCP Trademark Policy

## 1. Purpose

This policy explains permitted use of the AXCP name and logo.

## 2. Ownership

The "AXCP" name and the AXCP logo are associated with TradePhantom LLC and the AXCP project maintainers. No rights are granted except as explicitly stated in this policy.

## 3. Permitted Nominative Use

The following uses are permitted without prior authorization:

- Referring to AXCP in text to describe compatibility, integration, or use (e.g., "works with AXCP", "compatible with AXCP")
- Use in articles, talks, tutorials, and documentation, provided it does not imply official endorsement or affiliation
- Accurate statements about the AXCP project in press coverage or technical analysis

## 4. Prohibited Use

The following uses are **not permitted** without written authorization:

- Using the AXCP name or logo in a way that suggests official endorsement, partnership, or affiliation
- Using the AXCP logo as your product or company logo
- Naming a product or service so that users could reasonably believe it is the official AXCP project or an official offering from TradePhantom LLC
- Any use that implies the AXCP project or TradePhantom LLC has reviewed, approved, or certified your product

## 5. Logo Use

The AXCP logo may not be used without permission, except for fair-use in articles and press coverage where it clearly does not imply endorsement. When using the logo in permitted contexts, do not modify, distort, or alter the logo's colors or proportions.

## 6. Domain Names and Social Handles

Do not register domain names or social media handles that:
- Are confusingly similar to "AXCP"
- Imply official status or affiliation with the AXCP project
- Could mislead users into believing they represent the official project

## 7. Project Naming Guidance

When naming projects that work with AXCP:

**Acceptable:**
- "MyTool for AXCP"
- "Compatible with AXCP"
- "AXCP Integration for MyPlatform"
- "MyCompany's AXCP Connector"

**Not Acceptable (without authorization):**
- "AXCP Cloud"
- "AXCP Pro"
- "Official AXCP Service"
- "AXCP by MyCompany"

## 8. Permission Requests

For permission to use the AXCP name or logo in ways not covered by this policy, please open a GitHub issue in the [axcp-spec repository](https://github.com/tradephantomllc/axcp-spec/issues) with the subject "Trademark Permission Request" and include:

- Your name and organization
- Intended use of the AXCP name/logo
- Context and duration of use
