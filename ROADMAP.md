# AXCP Public Roadmap

## Current Status

| Version | Status | Description |
|---------|--------|-------------|
| **Core v1.0** | ✅ RELEASED | Secure Baseline Profile, 242 tests passing |

## Released Features (Core v1.0)

- QUIC Transport with TLS 1.3
- DID-based Decentralized Identity
- Ed25519 Cryptographic Signatures
- Replay Attack Protection
- Timestamp Validation
- Profile Negotiation (Handshake)
- Handler/Router Pattern
- Middleware Chain
- Error Response Framework
- Caching DID Resolver
- Integration Tests Suite

## Upcoming Releases

| Version | Key Features | Target |
|---------|--------------|--------|
| **Advanced v1.1** | mTLS client certificates, Attestation (SGX/SEV), Rate Limiting | Q2 2026 |
| **Enterprise v2.0** | Differential Privacy (mandatory), PII filtering, HIPAA/GDPR compliance, Audit trails | Q3 2026 |

## Future Roadmap

- **v2.1**: Multi-agent routing, Agent registry, Tool discovery
- **v2.2**: Remote OTEL streaming, Adaptive encryption
- **v3.0**: NEXCP convergence, Cross-ecosystem interoperability

## Open Governance

An Open Governance Working Group (WG) is planned to steer the future of the spec.
The WG will be open to vendors, researchers, and individual contributors.
